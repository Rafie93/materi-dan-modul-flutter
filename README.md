## 💻 Cara Menjalankan Modul

**1. Clone repositori dan masuk ke foldernya**

```bash
git clone https://github.com/Rafie93/materi-dan-modul-flutter.git
cd materi-dan-modul-flutter
```

**2. Pindah ke branch modul**

| Modul | Perintah |
| --- | --- |
| REST API – Simple News App with GetX | `git switch build-simple-news-app-with-getx` |
| Scheduling | `git switch flutter-background-tasks-and-notifications-tutorial` |
| Local Storage | `git switch flutter-mobile-data-persistence-and-crud-app` |

**3. Jalankan proyek**

Jika folder utama branch memiliki file `pubspec.yaml`, jalankan:

```bash
flutter pub get
flutter run
```

💡 *Silakan eksplorasi setiap branch untuk melihat implementasi lengkap dari masing-masing modul.*
